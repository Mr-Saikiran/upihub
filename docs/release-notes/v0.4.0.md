## UPI Hub 0.4.0

Install `techswitch-upihub-0.4.0.apk` on Android 7.0 or newer (allow "Install
unknown apps" for your browser or file manager). It installs over earlier
0.x builds signed with the same key.

### What's in this version
- Opens straight into a QR scanner; pay from a screenshot or a typed UPI ID.
- Lists every installed UPI app, including apps such as super.money whose
  link handler omits the default category.
- No built-in default: pick yours from all installed UPI apps on first launch.
- Payment apps screen: reorder, show or hide apps, sort A–Z.
- Asks for the amount when a QR code has none (needed by apps like Kiwi).
- Home-screen Scan & Pay widget; light and dark themes.

Verified with unit and Robolectric tests; not yet tested by the authors on
every UPI app. `SHA256SUMS` lists the file checksums.
